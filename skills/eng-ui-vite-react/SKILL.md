# UI: React + Vite

## Requirements
- TypeScript strict mode.
- No `any` types.
- Single API client module.

## Steps
1) Define routes and data loading strategy.
2) Implement UI components with typed props.
3) Add basic accessibility checks.
4) Run `npm run build`.
