# Ask Questions If Underspecified

Use this skill when a request is ambiguous or missing inputs (schemas, env vars, sample payloads, or constraints).

## Rules
- Stop before coding.
- Ask the minimum number of questions to proceed.
- Provide a clear checklist of missing inputs.

## Output
- 2–6 targeted questions
- A concise checklist of required inputs
- A short statement of what you will do once answered
