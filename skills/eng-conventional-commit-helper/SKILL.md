# Conventional Commit Helper

## Steps
1) Inspect git status/diff.
2) Group changes by intent.
3) Stage only one intent.
4) Commit with conventional format.

## Format
`<type>(<scope>): <subject>`

## Common types
- feat, fix, docs, refactor, test, chore
