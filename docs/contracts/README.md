# Contracts

- `config.schema.json`: autocodex configuration schema (YAML/JSON).
- `local-api.openapi.yaml`: Local API contract.
- `plugin-protocol.md`: External plugin protocol spec.
- `autonomy-tasks.schema.json`: Machine-readable tasks schema for autonomy loop (supports optional gate requirements like tests/evidence/verification).
- `autonomy-actions.schema.json`: ACTIONS block schema for Codex outputs (supports gate results including tests/evidence/verification).
- `autonomy-*.example.json`: Example payloads for validation and testing.
